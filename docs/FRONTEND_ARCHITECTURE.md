# 前端架构与验证

## 边界

业务 UI 使用 `src/api/` 的新版类型化 IPC 封装。`src/api/compat.ts` 已移除；旧 API 和旧类型仅作为历史代码保留，不进入业务页面依赖链。布局、路由、JSON v1 文件格式保持兼容。

| 层 | 职责 |
| --- | --- |
| `api/`、`types/` | IPC 参数与响应契约；UUID、RFC 3339 时间、完整更新字段 |
| `services/questionQueries.ts` | 批次加载关联资源，生成 `QuestionView`；科目过滤先于客户端分页 |
| `services/sourceCatalog.ts` | 从已加载来源推导级联选项，不再次读取数据库 |
| `services/questionEditor.ts` | 独立资源操作与编辑会话内的成功检查点，不承诺跨资源事务 |
| `composables/` | Vue 加载时序、编辑忙碌状态、错误与单独清理重试 |
| `views/`、`components/` | 页面交互、展示、局部筛选及表单草稿 |
| `types/transfer.ts` | 文件格式；仅导入导出边界映射 prompt/answer/analysis |

`QuestionView` 保留新版题目字段，只添加 source、subject、tags、srs。科目始终来自 Source；不构造旧字段别名，不把缺失 SRS 伪装成默认实体，也不在查询期间修复数据库。详情按需读取附件，列表不会读取附件内容。关联资源来自多个独立读取，不能视为跨 API 的单一数据库快照。

管理页与复习预览保持现有多维本地筛选语义，包括科目、标签名称等维度。需要分页的调用可以把新版支持的条件传入查询服务；科目是客户端条件，必须先取得完整候选集再筛选、分页。

## 保存与失败恢复

1. 来源选择先解析为已有来源或创建来源。同一前端实例只合并正在进行的相同来源解析，不缓存完成结果。
2. 标签按名称和颜色复用，附件独立上传。成功 ID 留在编辑会话中；后续步骤失败时，不回滚来源、标签或附件。
3. 题目提交完整可编辑字段和关系 ID；null 和空数组分别清空可空字段与关系。后端负责在创建题目的事务中初始化 SRS。
4. 题目提交成功后才尝试清理移除的附件。RESOURCE_IN_USE 表示仍被共享，应保留；NOT_FOUND 表示已不存在。其他清理错误保留待处理 ID，详情页可单独重试，不重新保存题目。

检查点只在当前编辑会话内保留，不提供跨刷新、跨窗口或未知 IPC 提交结果的幂等保证。取消编辑不删除独立资源；关闭页面后未关联资源的持久化管理由后续专门功能处理。标签管理通过新版删除接口操作资源，历史带“[已删除]”前缀的名称仍按原显示规则隐藏。

新加载使旧请求失效，组件卸载使所有未完成读取失效。来源级联选项同步从本地资源计算，避免选择切换时的查询竞态。

## 明确保留的例外

`src/api/platformExceptions.ts` 仅封装以下获准保留的命令：

- `legacy_opened_urls`：冷启动文件关联查询。
- `legacy_purge_synced_deletions`、`legacy_check_orphan_records`：设置页现有维护操作。

新增业务不能复用这些例外。`tests/apiBoundary.test.ts` 限制命令白名单，并检查业务代码不导入旧 API、旧类型或直接调用 invoke。

## 验证

运行 `pnpm test` 验证关联投影、客户端分页、来源复用、上传及题目提交失败重试、清理部分失败、完整字段清空、异步失效、JSON 兼容、HTML 内容和依赖边界。页面测试使用 happy-dom 挂载 Vue 组件及模拟 IPC，验证列表、新增、详情编辑与删除、复习、统计和批量导入结果。运行 `pnpm build` 执行 Vue 类型检查与生产打包。

桌面/移动端原生交互仍需在 Tauri 环境实测：新增带图题目、编辑并清空来源或标签、删除共享资源、复习提交、JSON 导入导出、原生分享、冷/热启动文件关联，以及设置页维护确认流程。自动化测试使用模拟 IPC，不代表这些原生场景已通过。

范围外缺陷在原位置留下 `TODO(out-of-scope)`，例如 App 中主题监听器的卸载清理；此次不实施这些修复。

分层依据：[Vue 组合式函数](https://vuejs.org/guide/reusability/composables)、[Vue 状态管理](https://vuejs.org/guide/scaling-up/state-management.html)。有状态逻辑放入 composable，无状态转换保留普通函数；共享状态仅用于跨页复习等确有需要的场景。
